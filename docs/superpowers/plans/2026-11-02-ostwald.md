# Ostwald (Hotarumori) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Der Ostwald – dunkler Wald mit gewundenen Pfaden, unregelmäßigen Lichtungen, Mohn-Übergang im Westen, Waldsaum vom See im Süden und dem Ritualplatz ganz hinten – wird zu echten Spieldaten.

**Architecture:** Wie beim Süden bleiben die Entwürfe die einzige Quelle der Optik. Eine Layout-Quelle (`east/layout.py`) legt Pfade, Lichtungen und Waldmasken einmal fest (feste Seeds) und wird von Entwürfen, Generator und Tests gemeinsam benutzt. `gen_south.py` wird zu einem Generator mit Ost-Anbau erweitert (Sammler `south/layers.py` wiederverwendet). Ein Regionsfeld (wie `mist_fields`) steuert Dunkelheit und Türkis im Post-Shader.

**Tech Stack:** Python 3 (numpy, Pillow, scipy nur lokal), Godot 4.7.2 GDScript/GLSL.

**Spec:** `docs/superpowers/specs/2026-11-02-ostwald-design.md` (Plan-Bild: Abnahme-Seite Schritt 37, Runde 3)

## Global Constraints

- Welt wächst von 900 × 3600 auf **1800 × 3600** Kunstpixel (10 × 18 Kacheln à 180 × 200). Alte Welt und Süden bleiben **bildgleich** (md5 der Vollbilder im Bereich x < 540 bzw. Süden x < 900, y ≥ 1200), Daten an Nähten dürfen sich ändern.
- Ostwald-Gebiet: Welt-x 540…1740, y 300…1700; Waldsaum nach Süden bis y 2900. Plankoordinaten (Abnahme-Bild) + (540, 300) = Weltkoordinaten.
- Ritualplatz ganz hinten (Plan: 1090/780 → Welt 1630/1080), nur über zwei lange Pfade erreichbar. Lichtungen unregelmäßig, Pfade stark gewunden, nichts im Raster. Einige Orte abseits (Gräber), andere direkt am Weg (Steinbrücke, Wasserplatz).
- Dunkel, mystisch, kein Herbstlaub; EINE kühle Lichtfarbe (Mond-/Türkisgrün). Warm bleibt Laterne, Feuer, Glenn. Glühwürmchen im Ostwald türkis.
- Stäbe/Stelen statt Schwertern; keine Texte, keine Rätsel.
- Keine Konturen, kein Schachbrett, keine Halbtransparenz in Bildern; Pixelgrafik nie skalieren. Sprites müssen im Dunkeln lesbar bleiben (Helligkeit gegen Boden prüfen).
- Neue Objekte immer neben vorhandene Spiel-Sprites stellen und Stil prüfen (Philips Regel). Neue Optik/Klänge zuerst auf die Abnahme-Seite (`build/preview/abnahme_neu`), Okay abwarten, Zone für Zone; ausgeliefert wird auf einmal.
- Python-Tests unter `tools/tests` ohne scipy (CI); Generator-Tests mit scipy lokal. Schwere Läufe einzeln, `nice`, Akku ≤ 45 °C. Keine Secrets, keine Attribution-Zeilen in Commits. Kommentare 1–2 Zeilen.

## Review Focus

1. Erreichbarkeit: jeder Pfad-/Lichtungspixel vom Waldtor erreichbar; Ritualplatz über zwei getrennte Wege; keine Sackgassen außer den benannten Nebenlichtungen.
2. Naht Mohnfeld → Wald und See → Waldsaum: keine Kante (Ton, Dichte, Bodenstruktur), Tannen-Platzhalter an x 540 weg, Süd-Ostrand (Tannen/Nebelwand) am Waldsaum geöffnet.
3. Lesbarkeit im Dunkeln: Mönch, Grabsteine, Stelen, Laternen heben sich vom Boden ab; Lichtschacht und Mondlicht überstrahlen nicht (Bloom).
4. Leistung: Welt doppelt so breit, deutlich mehr Sprites – Aktivierer/Kachel-Laden dürfen nicht linear über alles laufen; Speicher der 10×18 Kacheln auf dem Handy.
5. Begehbarkeit je Objektart: Baumstamm, Grabstein, Steinkreis, Teich (tief) gesperrt; Pfad, Lichtung, flaches Ufer, Steg begehbar; nie „unterste Sprite-Pixel“.
